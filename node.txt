1. OVERALL BRIEF CONCEPT OF OUR WEBSITE
--------------------------------------------------------------------------------
THAMILI AI is a state-of-the-art AI-powered Video & Multimedia Generation Studio 
tailored with rich cultural aesthetics (Tamil heritage combined with futuristic 
cyberpunk design). The platform provides creators, directors, writers, and artists 
with an end-to-end suite of generative tools:

• Prompt-to-Video Generation: Transform natural language descriptions into 4K 
  cinematic videos with fine-tuned camera motions, visual styles, and lighting moods.
• Image-to-Video Animation: Animate static character portraits, sceneries, or concept 
  art into realistic fluid video sequences.
• Character Consistency System: Select and lock characters across multiple video 
  generations to maintain facial features, attire, and identity continuity.
• AI Prompt Engineering Pipeline: Automatically expand simple prompts into 4K 
  hyper-detailed cinematic directives before passing them to video diffusion engines.
• 3D Tamil Glyph Neural Sphere Generation Animation: An interactive 3D canvas 
  featuring 340 Fibonacci-distributed Tamil glyph nodes with real-time kinetic 
  physics, hover collapse, and cursor supernova splash impulses while generating.
• Custom Neural Video Player: High-performance video player supporting timeline 
  scrubbing, speed variations, loop toggles, aspect-ratio switching, and HD downloads.
• Dual Language Interface: Fully localized in English and Tamil (தமிழ்) with instant 
  switching across all buttons, descriptions, and notifications.
• Local History & Token Accounting: Offline-first localStorage persistence for 
  saved creations, video library exports, and simulated token usage tracking.

4. BACKEND ARCHITECTURE & SERVICES
--------------------------------------------------------------------------------
• Runtime: Node.js (ES Modules) with Express.
• Supported Modes:
  a) Vite Dev Server Plugin (vite.config.js): Integrates API proxy directly into dev port 5173.
  b) Standalone Production Server (server.js & server/server.js): Runs on port 5000/3000.

[Backend Endpoints]:
  • POST /api/openrouter/enhance-prompt
    - Accepts user prompt, target visual style, resolution, aspect ratio, and characters.
    - Sends structured instruction to OpenRouter (openai/gpt-4o-mini).
    - Returns 4K expanded prompt paragraph.

  • POST /api/openrouter/chat
    - Handles conversational multi-turn messaging with OpenRouter.

  • POST /api/video/generate (and aliases: /api/generate-video, /api/gemini/generate-video)
    - Orchestrates video generation using Google Gemini Veo API.
    - Automatically enhances prompt via OpenRouter if not already expanded.
    - Manages asynchronous operation polling and returns final MP4 video URI.

  • POST /api/generate-image-to-video (and alias: /api/gemini/generate-image-to-video)
    - Receives source image and motion prompt.
    - Triggers Gemini Veo image-to-video animation model.

  • POST /api/enhance-prompt
    - Unified prompt enhancement endpoint (prioritizes OpenRouter, falls back to Gemini Flash).

  • GET /api/health (and alias: /api/gemini/health)
    - Real-time diagnostics for configured OpenRouter and Google Gemini API keys.

  • GET /generated/:filename
    - High-efficiency HTTP 206 Partial Content streaming for generated video files.

  • ALL /api/fal/proxy
    - Secure raw proxy forwarding for @fal-ai/client without exposing FAL_KEY to frontend.


5. ALL WORKING FUNCTIONS & UTILITIES REFERENCE
--------------------------------------------------------------------------------
[src/services/videoService.js]:
  • enhancePrompt(prompt, options)
    - Calls backend /api/openrouter/chat or /api/enhance-prompt.
  • generateTextToVideo(prompt, options)
    - Submits text prompt to /api/video/generate with style/ratio/camera parameters.
  • generateImageToVideo(image, prompt, options)
    - Submits image and prompt to /api/generate-image-to-video.
  • testBackendConnection()
    - Queries /api/health to confirm backend and AI service availability.
  • normalizeErrorMessage(err, defaultMsg)
    - Sanitizes raw network and API exceptions into clear user-friendly guidance.

[src/services/openrouterService.js]:
  • enhancePromptWithOpenRouter(options)
    - Direct client helper for OpenRouter prompt expansion.
  • chatWithOpenRouter(messages, options)
    - Direct client helper for OpenRouter chat completions.

[src/utils/historyStorage.js]:
  • saveHistoryItem(item)
    - Persists generated videos with thumbnail, prompt, parameters, and timestamps.
  • getHistoryItems()
    - Retrieves saved creation history sorted by most recent.
  • deleteHistoryItem(id)
    - Removes individual item from localStorage.
  • toggleSavedVideo(id)
    - Bookmarks or unbookmarks a video in the user collection.
  • captureCanvasThumbnail(videoElement)
    - Captures a lightweight JPEG base64 snapshot from a playing video for instant gallery thumbnails.

[src/utils/tokenUsageStorage.js]:
  • getTokenBalance()
    - Returns current token balance (e.g. 500 initial credits).
  • consumeTokens(amount, description)
    - Deducts tokens and records transaction history.
  • resetTokenBalance(amount)
    - Resets credits back to default allocation.

[src/utils/promptActionInterpreter.js]:
  • interpretVideoPrompt(promptText)
    - Parses prompts for cinematic keywords (e.g. drone shot, close up, volumetric light).


6. ENVIRONMENT VARIABLES (.env)
--------------------------------------------------------------------------------
• GEMINI_API_KEY      : Google Gemini API key for Veo video generation & Gemini Flash.
• OPENROUTER_API_KEY  : OpenRouter API key for high-speed prompt enhancement & chat.
• OPENROUTER_MODEL    : Target LLM model (default: openai/gpt-4o-mini).
• PORT                : Server port (default: 5000 / 3000).
• FAL_KEY             : (Optional) Fal.ai proxy key for specialized diffusion models.
